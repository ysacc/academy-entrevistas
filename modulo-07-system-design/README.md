# Módulo 7 — System Design básico

## Objetivos

- Aclarar requisitos antes de diseñar.
- Separar funcionales y no funcionales.
- Dibujar componentes y flujo de datos.
- Identificar almacenamiento, APIs, cache y colas cuando aporten valor.
- Explicar trade-offs sin sobrediseñar.

## Ejercicio

Diseña uno de estos sistemas:
- chat de soporte;
- acortador de URLs;
- catálogo e-commerce;
- sistema de notificaciones;
- dashboard con datos en tiempo real.

Usa `starter/template.md`.
