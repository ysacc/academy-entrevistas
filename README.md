# Academy — Preparación para Entrevistas Tech

Programa práctico y modular para preparar procesos de selección en desarrollo de software.

## Objetivo

Entrenar al alumno para comunicar su experiencia, resolver preguntas técnicas, enfrentar live coding y debugging, razonar sobre diseño de sistemas y desenvolverse en entrevistas conductuales y en inglés técnico.

## Estructura

1. Diagnóstico y estrategia de búsqueda.
2. CV, LinkedIn, GitHub y pitch profesional.
3. JavaScript / TypeScript y fundamentos web.
4. React, frontend y APIs.
5. Backend, SQL y Git.
6. Live coding y debugging.
7. System Design básico y decisiones técnicas.
8. Entrevista conductual, inglés y simulación final.

Cada módulo público contiene:

- `README.md`: material y ejercicios del alumno.
- `starter/`: material inicial cuando corresponde.

Las preguntas internas, follow-ups, criterios de evaluación, señales de alerta y guías de simulación se mantienen en un repositorio privado del instructor.

## Metodología

La preparación se basa en práctica deliberada. El alumno debe responder en voz alta, justificar decisiones, escribir código bajo presión moderada y recibir feedback concreto.

La IA puede usarse para practicar o investigar, pero durante una simulación el alumno debe demostrar comprensión propia.

## Evaluación

No se busca memorizar respuestas. Se evalúa claridad, razonamiento, fundamentos, comunicación, capacidad de detectar errores y habilidad para reconocer límites.

## Ecosistema Academy

Ruta técnica recomendada:

1. [Desde Cero](https://github.com/ysacc/academy-desde-cero) — fundamentos web.
2. [Frontend React](https://github.com/ysacc/academy-frontend-react) — especialización frontend.
3. [Full Stack](https://github.com/ysacc/academy-fullstack) — desarrollo Full Stack y trabajo colaborativo.

Programas complementarios:

- **Preparación para Entrevistas** — puede tomarse después de cualquiera de las rutas anteriores según el puesto objetivo.
- [Mentoría](https://github.com/ysacc/academy-mentoria) — acompañamiento individual y roadmap profesional.

### Cuándo usar este programa

No exige haber completado todos los cursos. El contenido debe adaptarse al stack, seniority y tipo de vacante del alumno.
