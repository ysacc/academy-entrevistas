# Metodología

Este repositorio es modular y no define una duración comercial fija.

Cada módulo combina:
- explicación breve;
- práctica oral;
- ejercicio técnico;
- simulación;
- feedback;
- plan de mejora.

## Regla principal

Una buena respuesta técnica debe mostrar cómo piensa el candidato, no solo el resultado final.

## Simulaciones

El instructor debe aumentar progresivamente la presión:
1. práctica abierta;
2. tiempo limitado;
3. preguntas de seguimiento;
4. interrupciones o cambios de requisito;
5. simulación completa.

## Feedback

Usar siempre tres bloques:
- qué funcionó;
- qué debe mejorar;
- qué practicar antes de la siguiente sesión.
