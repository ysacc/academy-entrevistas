# Evaluación

## Dimensiones

- Comunicación y estructura de respuesta.
- Dominio técnico.
- Razonamiento y trade-offs.
- Debugging.
- Calidad de código.
- Gestión del tiempo.
- Capacidad para pedir aclaraciones.
- Honestidad ante algo que no conoce.

## Escala sugerida

- 1: no puede responder o depende de memorización.
- 2: respuesta parcial con errores importantes.
- 3: respuesta correcta pero poco profunda.
- 4: respuesta sólida y bien razonada.
- 5: respuesta clara, profunda, con trade-offs y ejemplos.

La simulación final debe comparar el resultado contra el diagnóstico inicial.
