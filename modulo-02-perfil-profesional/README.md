# Módulo 2 — CV, LinkedIn, GitHub y pitch

## Objetivos

- Presentar experiencia con impacto y contexto.
- Evitar listas de tecnologías sin evidencia.
- Construir un pitch profesional breve.
- Preparar respuestas sobre proyectos y logros.

## Ejercicio

Prepara:
1. pitch de 30 segundos;
2. pitch de 90 segundos;
3. explicación de un proyecto en formato contexto → problema → acción → resultado;
4. README de un proyecto destacado.

## Entrega

Completa `starter/pitch.md` y graba o practica las respuestas en voz alta.
