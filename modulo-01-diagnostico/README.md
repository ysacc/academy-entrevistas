# Módulo 1 — Diagnóstico y estrategia

## Objetivos

- Identificar fortalezas y brechas.
- Definir roles objetivo.
- Diferenciar Junior, Mid, Senior y Lead por expectativas reales.
- Construir un plan de preparación.

## Actividad

Completa `starter/diagnostico.md` y selecciona 3 ofertas reales similares al rol objetivo.

## Entrega

- Rol objetivo.
- Stack principal.
- 3 fortalezas.
- 3 brechas.
- 3 historias profesionales que puedas contar.
- Lista priorizada de temas técnicos a practicar.
