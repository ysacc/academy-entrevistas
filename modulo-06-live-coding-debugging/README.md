# Módulo 6 — Live coding y debugging

## Objetivos

- Pensar en voz alta.
- Pedir aclaraciones antes de programar.
- Empezar por una solución simple y correcta.
- Probar casos normales y bordes.
- Depurar de forma sistemática.

## Reglas

Durante la práctica:
1. repite el problema;
2. aclara supuestos;
3. propone solución;
4. programa;
5. prueba;
6. analiza complejidad o mejoras.

## Retos

Usa `starter/retos.md` sin consultar soluciones durante la simulación.
